# Warthog

## Steam copy draft

The Warthog is a heavy, single-pilot jet built for close air support. Build it from specialized aircraft components, crew it with an operating pilot, and use its sortie command while it is on station above a map. It can attack along a chosen line without landing, but every run uses steel and its time in the air consumes fuel.

## Current build facts

- One pilot is required to operate it.
- Footprint is 12 by 12 cells.
- Requires Jet Propulsion research.
- Uses dedicated jet fuel.
- Current build cost: 2 jet engines, 2 intakes, 2 exhausts, 15 jet-parts items, 2 jet-fuel tanks, 3 car wheels, 500 steel, 4 industrial components, and 2 advanced components.
- Build work: 16,000. Current vehicle market value: 6,000.
- The XML currently uses a tier-2 VVE stat extension despite being stored under a Tier4 folder. Avoid calling it Tier 4 in public copy until that classification is reconciled.

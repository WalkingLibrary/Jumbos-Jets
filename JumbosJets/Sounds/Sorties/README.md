# Replaceable sortie audio

- `StrafeFire.wav`: played once per actual shot. The 0.65-second placeholder overlaps following shots (normally 0.1 seconds apart).
- `StrafeTail.wav`: played when the pass finishes, overlapping remaining firing samples and continuing afterward. The placeholder lasts 2.5 seconds.
- `StrafeRun.wav`: an optional sustained placeholder for planes configured with `useSingleStrafeSound=true`. It loops for the entire approach and pass, then fades out when the run ends.

These are original synthesized placeholders, generated by `Tools/New-SortiePlaceholderSounds.ps1`. Replace the WAV files at the same paths with your own audio, rebuild and restart RimWorld. No C# changes are required. The placeholders are PCM 16-bit mono WAV, with extra gain and headroom to make them audible at normal game volume.

Definitions and volume/voice limits are in `1.6/Defs/SoundDefs/SortieSounds.xml`. One-shot sounds use `onCamera=true` and are started with `PlayOneShotOnCamera(targetMap)`: they play only while viewing that map, without distance attenuation. The sustained sound also uses `onCamera=true` and is started with `TrySpawnSustainer(SoundInfo.OnCamera())`; it is explicitly ended when the run finishes or is canceled. Keep `onCamera=true` unless the C# playback call is also changed. The two one-shot sounds use separate definitions without an exclusive sound slot, allowing them to overlap. Stock bomb audio is disabled for these explosions so it does not mask the sortie sounds. Already-playing audio finishes naturally if orders change; audio playback itself is not saved or replayed after loading.

Set `<useSingleStrafeSound>true</useSingleStrafeSound>` in a plane's sortie comp to use one looping `strafeRunSound` for the entire approach and impact sequence. Leave it false for the per-shot `firingSound` mode. `strafeRunSound` must reference a `<sustain>true</sustain>` SoundDef. `afterSound` still plays at the end in either mode.
